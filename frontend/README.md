# Ayurlex Frontend

Frontend application for **Ayurlex** — AI-Powered Ayurveda Intellectual Property & Regulatory Research Intelligence.

Refer to the main [Root README.md](../README.md) for full project architecture, vision, statutory tenets, and backend specifications.

## Quick Start
```bash
# Install dependencies
npm install

# Start Vite dev server (port 5173)
npm run dev

# Full TypeScript check & production build
npm run build
```

## Implemented Workspaces
- `/` (`landing`): Hero section and 5-domain Ayurveda IPR cards.
- `/research`: Multi-phase chat research workspace with clickable statutory citation chips, confidence badges, abstention panels, and side-by-side jurisdiction comparison.
- `/classification`: 5-step interactive wizard assessing First Schedule inclusion, novel extraction, Section 3(p) patent bars, and Rule 158B licensing proof.
- `/compliance`: Biological Diversity Act (ABS Form III) and TKDL prior art guidance.
- `/admin`: Corpus freshness, statutory source health, and indexed records metrics.
